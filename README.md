# Benchmark: Human-Like Grasp Evaluation

This branch contains a modified version of [DexGraspBench](https://github.com/JYChen18/DexGraspBench), adapted to evaluate **human-like robotic grasp synthesis** results generated from the `main` branch of this repository.

The benchmark supports large-scale analysis and visualization of open-loop grasps using a variety of physical and analytic metrics.

---

## 🔍 Key Features

- Evaluate grasp success using physics simulation (MuJoCo)
- Analyze force closure, contact consistency, and penetration depth
- Merge and visualize selected grasp results using `task=mergeobj`
- Compatible with grasps generated by [BODex](https://github.com/JYChen18/BODex)

---

## 🔧 Modifications from Original DexGraspBench

This benchmark version has been adapted for human-like grasp analysis with the following key changes:

- Integrated with my own synthesized grasps from the [`main`](https://github.com/Zeyu1-oss/human-like-dexgrasp/tree/main) branch
- Streamlined `task=mergeobj` usage to select and render 200 samples per grasp type for visual validation
- **Revised success criteria**: added a new condition requiring **sufficient number of contacting hand links** to count a grasp as successful (reflecting structured, human-like contact)

- Removed unused baseline modules for simplicity

> Core metric implementations (AUC, FC analysis, contact stats) remain identical to the original DexGraspBench.
